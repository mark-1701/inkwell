# Inkwell

A personal blogging CMS for creating, managing, and publishing blog posts.

## Tech Stack

- Next.js
- React
- TypeScript
- Prisma
- PostgreSQL
- Tiptap
- Zustand
- React Hook Form
- AWS S3
- Tailwind CSS

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```
